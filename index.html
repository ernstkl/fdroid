MTPV: Multi-Tablet PDF Viewer

Sheet music and PDFs on one tablet or spread across several, one page per screen, with notes.

Installing

Do this on each Android tablet you want to use (Android 10 or newer).

  1. Install an F-Droid app. Open f-droid.org, tap Download F-Droid and open the downloaded file.
    f-droid.org
    Android asks whether your browser may install apps: allow it. If Google Play Protect offers to scan the app, choose Scan.
  2. Add this app repository. Tap the button, choose to open it with F-Droid and confirm Add repository.
    Add repository
    If F-Droid does not open: in F-Droid go to Settings → Repositories → + and enter https://ernstkl.github.io/fdroid/repo.
  3. Install MTPV. Search for MTPV in F-Droid and install it. Allow F-Droid to install apps when Android asks. F-Droid shows you updates later.
  4. Connecting tablets: the first time, MTPV asks for the location permission. Android needs it for the direct connection between tablets; MTPV never reads your position.

Without F-Droid

Download mtpv-x.y.z.apk from the releases page and open it. Updates do not come by themselves then.
